# Palette

AppDock 0.255.0以降。定型文とWindowsクリップボード履歴を、元の入力先を保持したパレットから貼り付ける。

## 定型文

「設定 → Palette → 定型文」で追加・編集・削除・有効切替・並べ替えを行う。名前、複数行の本文、有効状態を登録する。追加・編集はOKで登録単位に即時保存し、取消ではファイルを書き換えない。並び順が候補の順序になる。

登録内容の正本は`snippets.json`（schemaVersion:1、items配列のid/name/text/enabled）。`configuration` scopeのファイルStorageを使い、通常のApplet保存先選択に従う。EXE隣の`data/storage/at365.palette/shared/files/snippets.json`、または`devices/<端末名>/files/snippets.json`へ保存する。切替時にファイルのコピー・移動・統合はしない。外部編集は再読込またはパレットを開き直したときに反映し、保存競合は上書きせず拒否する。本文や登録一覧をsettingsへ埋め込まない。

文字ライブラリーのグループは参照しない。既存グループからの自動取り込みは行わない。

設定タブは「動作設定 → 定型文」の順に表示する。

## 操作と動作設定

`at365.palette.snippets.open`で定型文、`at365.palette.history.open`でWindowsの履歴を開く。初期キー割り当てはなく、コマンドトリガーから割り当てる。

上下キー、PageUp/PageDown、Home/Endで選び、Enterまたは先頭10件の1～9/0で貼り付ける。左右キーで両パレットを切り替え、Escapeまたは入力先変更で閉じる。定型文の管理ボタンはPaletteの設定を開く。Windows履歴の無効化・アクセス拒否・削除済み項目は本体の共通入力基盤で処理する。履歴はWindowsが所有し、PaletteのStorageへ複製しない。

「動作設定」で両パレットの表示行数（既定8）・初期幅（既定370px、最小260px）、操作ガイド（既定ON）、定型文の履歴追加（既定ON）を変更する。動作設定だけは通常のApplet settingsに保存する。ドラッグしたサイズは開いている間だけ保持し、閉じて開き直すと設定幅へ戻る。

Appletを停止・再起動すると、所有するパレットと未完了の貼り付けを取り消す。Windowsへの送信受付と、対象アプリへの反映確認は区別する。

JSON表示と設定の既定値復帰は通常の動作設定を対象とする。定型文の登録内容は一覧で編集・削除し、設定リセットではStorageファイルを削除しない。
